# TSA Data to Value Challenge 2569

ต้นแบบเว็บไซต์ภาษาไทยสำหรับรับสมัครและนำเสนอผลการแข่งขันเพิ่ม/ปรับปรุงข้อมูลกีฬา ประกอบด้วยหน้าต้นแบบ 11 หน้า พร้อมหน้าจัดการเพิ่มเติมสำหรับภารกิจ กลุ่มจังหวัด คำทักท้วง ประวัติ และบทบาทผู้ใช้

## เริ่มใช้งาน

เปิด PowerShell ในโฟลเดอร์นี้แล้วรัน:

```powershell
python -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000/pages.html`

## ส่วนที่ทดลองได้

- แบบฟอร์มสมัครทั้งหน้าจอคอมพิวเตอร์และมือถือ ตรวจข้อมูลที่จำเป็น, จัดรูปแบบเบอร์โทร, เลือกจังหวัดครบ 77 จังหวัด, แสดงกลุ่มจังหวัด และออก `TSA69-XXXXXX`
- หน้าที่แสดงแบรนด์ใช้โลโก้ใน `assets/tsa-logo.png` ในส่วนหัวและแถบหลังบ้าน โดยตัดข้อความชื่อโครงการข้างโลโก้ออก
- หน้าแบบฟอร์มแสดงสถานะความครบถ้วนของข้อมูลพร้อมคำแนะนำเมื่อกรอกไม่ครบ
- ปุ่มส่งใบสมัครอยู่ท้ายแบบฟอร์ม และรายการหน้า `pages.html` เปิดหน้าเป้าหมายในแท็บใหม่
- บันทึกข้อมูลสมัคร/ฉบับร่างไว้ใน `localStorage` ของเบราว์เซอร์ และแสดงสถานะในหน้า “การสมัครของฉัน”
- คำนวณคะแนนบุคคลด้วย `window.TSAChallenge.calculateIndividualScore()` และตรวจเงินรางวัลด้วย `window.TSAChallenge.applicantAward()`
- ค้นหาชื่อย่อ/จังหวัดในหน้าผล และส่งออกตารางตัวอย่างเป็น CSV UTF-8 BOM จากหน้าผู้สมัครหลังบ้าน

## ข้อจำกัดสำคัญ

นี่เป็น **front-end demo เท่านั้น** ข้อมูลผู้สมัครเก็บในอุปกรณ์ปัจจุบัน ไม่มีฐานข้อมูล/บัญชีผู้ใช้/การควบคุมสิทธิ์ฝั่งเซิร์ฟเวอร์ ไม่มีการส่งอีเมลจริง และข้อมูลในหน้าผล/หลังบ้านยังเป็นข้อมูลตัวอย่าง การเก็บข้อมูลใน `localStorage` ไม่ใช่มาตรการรักษาความลับ จึงห้ามใช้เก็บข้อมูลบุคคลจริงหรือเปิดใช้งานรับสมัครจริง

ก่อนใช้งานจริงต้องเชื่อมบริการ backend ที่มีการยืนยันตัวตนและตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์, ฐานข้อมูล, audit log ที่แก้ย้อนหลังไม่ได้, ระบบอีเมลของหน่วยงาน, การจัดการไฟล์แนบ, การตรวจสอบผล/การอนุมัติแบบแบ่งหน้าที่ และตรวจสอบการจัดกลุ่มจังหวัดกับประกาศทางการ
